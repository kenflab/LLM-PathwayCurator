# Manuscript figure and evidence map

This map follows the Figures 1–3 and Supplementary Data 1–4 layout in the
2026-10-22 coauthor draft. It identifies retained analyses and their roles; it
does not change study locks, source values, human labels or the manuscript.
The machine-readable entry point is [`paper/FIGURE_MAP.csv`](../../FIGURE_MAP.csv).
The original map is preserved byte-for-byte in
[`archive/FIGURE_MAP_original.csv`](archive/FIGURE_MAP_original.csv).

## Render the manuscript figures from saved results

Provide the external coauthor package's `supplementary_data` directory. These
commands require Python, NumPy and Matplotlib; they make no model requests and
do not fit expression models or regenerate human labels.

```bash
export CRM_R1_SUPPLEMENT="/absolute/path/to/coauthor_package/supplementary_data"

python paper/revision/CRM_R1/figures/plot_figure2.py \
  --data-dir "$CRM_R1_SUPPLEMENT/Supplementary_Data_1_TCGA" \
  --outdir /absolute/path/to/new_figure2

python paper/revision/CRM_R1/figures/plot_figure3.py \
  --data-dir "$CRM_R1_SUPPLEMENT/Supplementary_Data_2_DEX" \
  --outdir /absolute/path/to/new_figure3
```

Each output directory must be new. Renderers write PNG/PDF/SVG and a manifest
with input, implementation and output hashes. Figure 2 also writes its selected
HNSC source table and pairwise overlap table into that new output directory.
It does not write to the supplied source tables. Numerical inputs and panel
definitions are the same as the coauthor-package renderers.

Figure 1 is the supplied conceptual artwork. It is not regenerated by these
scripts. The optional `plot-source` command is a general tool display, distinct
from the fixed manuscript composition; see the [visualization guide](../../../docs/visualization.md).

## Reproduce upstream analyses separately

- TCGA: [`paper/scripts/tcga_rebuild/README.md`](../../scripts/tcga_rebuild/README.md)
  documents the saved OVFIX1 input snapshot and the pinned analysis commit
  `764b18ec0140d9c878bf7866f129e6513ac751d4`. The runner invokes the retained
  ranking/enrichment code. Use a fresh output directory when rerunning it.
- Source/q comparison: `paper/scripts/summarize_tcga_source_baseline.py` reads
  completed source reports and verifies identities against the enrichment data.
- DEX prose checking used `grounding.py` at
  `674edd05dca863bd424106df4baa07efd2ed911a`. The study-specific human-response
  intake and analysis driver are in the external clarified DEX package. The
  public Figure 3 renderer consumes its summaries; it is not the intake validator.
- Three-rater HNSC: `65_revision_r06.py` and `v17_r06.py` document the preserved
  statement-specific analysis. The saved analysis commit is
  `baf343390dab82dc1ef6759b0d0244ad046004db`. Ratings must stay linked to the text
  and sources actually shown to those evaluators.
- Other retained analyses: the [research script map](scripts/README.md) and
  per-experiment protocols describe the existing runners and saved-result
  reporters. The submission reporter renders archived split results; it does
  not refit the 22-cohort split experiment.

## Availability and limits

This code update publishes the map and renderers. It does not publish private
rating forms, correspondence, the coauthor Word files or the external input
bundles. The current draft's saved source tables are in Supplementary Data 1–4,
not automatically in the historical `paper/source_data/` directories.
Consequently, a Git checkout alone is not a complete end-to-end study bundle.
The map explicitly marks external artifacts and remaining upstream dependencies.

Before submission, the deposited source-data package and release must use this
same mapping and preserve analysis-specific version records. A new plotting
commit does not replace the recorded versions used for fits or text checks.
No quantitative accuracy, usability gain or improved biological selection is
inferred from a cleaner figure or the presence of a visualization feature.
