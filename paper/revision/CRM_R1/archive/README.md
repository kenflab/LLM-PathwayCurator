# Historical revision records

These notes record earlier plans, implementation versions and development
findings. Their text is retained for provenance; they are not current execution
instructions. Use the [revision README](../README.md) as the current entry point.

Version identifiers in historical records are necessary to link a result to
its original code and protocol. They do not belong in names of public runtime
modules. For exact historical paths and code hashes, use commit
[`b069e8a`](https://github.com/kenflab/LLM-PathwayCurator/tree/b069e8ad3d916618adcf26af0202748790c3ca20).

The repository reorganization does not change past outcomes, ratings or locks.
Private manuscripts, correspondence, rater returns and new analysis outputs stay
in the existing external data root. They should not be added to public Git.
